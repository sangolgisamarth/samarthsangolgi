# Portfolio

Run locally (browsers block JSON loading from file://):
    python3 -m http.server 8000   -> open http://localhost:8000

Edit content only in /data: meta, stats, skills, experience, projects, hackathons,
certifications, courses, education, profiles. Add images in /images and a resume.pdf.
Project items may also have "github" and "demo" links. Hackathons/certs accept "link".
Free hosting: push the folder to GitHub Pages.
